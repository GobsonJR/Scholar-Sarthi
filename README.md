# 🎓 Scholar Sarthi

### AI-Powered Scholarship & Fellowship Management Platform

Scholar Sarthi is a full-stack scholarship and fellowship management platform designed to simplify application processing through intelligent document processing, verification, eligibility assessment, mismatch detection, and human officer review.

The platform connects applicants and scholarship officers through a transparent workflow that combines AI-assisted document analysis with configurable eligibility rules and human decision-making.

---
